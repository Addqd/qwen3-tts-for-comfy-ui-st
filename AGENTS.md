# Постоянные правила проекта

## Область проекта

- Проект предоставляет локальный Qwen3-TTS backend для SillyTavern, ComfyUI и других OpenAI-compatible клиентов.
- Основная модель: `Qwen/Qwen3-TTS-12Hz-0.6B-Base`. Не заменять без прямого разрешения пользователя.
- Backend не зависит от конкретной LLM и принимает уже готовый текст.
- Модель загружается только в отдельном backend-процессе; ComfyUI-ноды остаются лёгкими HTTP-клиентами.
- Общие voice library и preprocessing находятся в лёгком backend facade; neural inference выполняет persistent qwentts.cpp.

## Безопасность

- Все серверы слушают только `127.0.0.1`; не использовать `0.0.0.0`.
- Не изменять глобальный Python, реестр, BIOS, драйверы, Defender или Execution Policy.
- Не завершать чужие процессы и не управлять External AI workload.
- Не изменять существующие SillyTavern/ComfyUI/LLM.
- До явного подтверждения не создавать junction/symlink и не копировать файлы в существующий ComfyUI.
- Не удалять файлы вне проекта.
- Backend-пакеты устанавливать только в `.venv`.
- Голос клонировать только при наличии разрешения; приватный текст и WAV не писать в обычные логи.

## Совместимость и качество

- Целевая ОС: Windows, PowerShell, нативный запуск без Docker/WSL2.
- Целевая GPU: RTX 2070 Super (Turing, 8 GB). Не включать автоматически BF16, FlashAttention 2, Triton, torch.compile и экспериментальные kernels.
- Поддерживать `cpu`, `cuda`, `cuda_on_demand`, `auto`; auto только наблюдает внешнюю нагрузку.
- Язык синтеза передавать явно как Russian/ru.
- Voice cloning Base-модели выполнять через референс и точную транскрипцию согласно актуальному официальному API.
- Не заявлять работоспособность режима или качество аудио без реального теста.

## Инженерный процесс

- После изменения кода запускать релевантные тесты.
- Ошибки API должны быть понятными JSON-ответами; полный входной текст не логировать.
- PID хранить в runtime-файле; stop-скрипт завершает только процесс проекта.
- Версии зависимостей фиксировать; документацию и TASK_LOG обновлять по фактическим результатам.
- Сторонние репозитории использовать как референсы, не копировать вслепую.
