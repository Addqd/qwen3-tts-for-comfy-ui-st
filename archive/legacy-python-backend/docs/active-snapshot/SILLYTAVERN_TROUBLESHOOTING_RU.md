# SillyTavern + Qwen3-TTS: диагностика

## Backend недоступен на 8020

Запустите `start-tts.bat`, затем откройте `http://127.0.0.1:8020/health`. Проверьте `logs/server.err.log`. Не запускайте второй backend поверх занятого порта.

## SillyTavern недоступна на 8000

Запустите её собственный `Start.bat`. Проект намеренно не запускает, не останавливает и не перенастраивает SillyTavern.

## Нет звука

- Provider — OpenAI Compatible.
- Endpoint — полный `http://127.0.0.1:8020/v1/audio/speech`.
- Model — `tts-1-ru`.
- Включён **Enable**, для автоматической речи — **Auto-generation**.
- Персонажу назначен существующий voice ID, после изменения нажат **Apply**.
- В браузере разрешено воспроизведение для localhost.

## Voice not found

Откройте `http://127.0.0.1:8020/v1/voices`, вручную добавьте точный ID в provider и заново примените Voice Map. Backend поддерживает `/admin/reload-voices`, если профиль был добавлен после запуска.

## Повествование пропало

Отключите **Only narrate quotes** в TTS SillyTavern. По контракту backend озвучивает весь ответ, а neutral-повествование ему тоже необходимо получить.

## Emotion tag не сработал

Правильно:

```text
[voice:angry] "Я предупреждала!"
```

Тег должен находиться непосредственно перед полной репликой в ASCII-кавычках. `[voice:angry] Она ответила.` намеренно даёт neutral. После закрывающей кавычки Router автоматически возвращается к neutral.

## Tag слышен в аудио

Известные, неизвестные и malformed service tags удаляются до worker. Если слышится старое поведение, перезапустите backend, чтобы процесс загрузил текущий код. Также убедитесь, что сторонний Regex не преобразует tag до отправки.

## Синтез медленный или Stop не мгновенный

На CPU генерация может быть медленнее реального времени. Browser Stop прекращает playback/очередь UI, но не обязательно прерывает уже выполняющийся inference. Для backend используйте `./stop.ps1`; чужие Python/Node процессы проект не завершает.

## Безопасный откат UI-настроек

Проект не записывает настройки SillyTavern, поэтому автоматического uninstall нет. Если вы вручную изменили provider, верните прежние значения через UI или восстановите собственный backup `settings.json` при остановленной SillyTavern.
